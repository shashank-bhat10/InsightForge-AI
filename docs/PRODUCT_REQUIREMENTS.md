# Current product scope

Audience: a student or interviewer running a local tabular analytics demonstration.

Core flow: register through the API, sign in, upload a small CSV/Excel file, inspect statistics and quality, compare basic models, generate a trend forecast, and optionally ask Gemini questions.

Acceptance evidence is recorded in [VERIFICATION.md](VERIFICATION.md). The project must communicate missing credentials and invalid data clearly, protect resource ownership, and document its evaluation limits. Statistical summaries must not be described as generative AI output.

Not in current scope: enterprise deployment guarantees, high-volume processing, automated business decisions, model serving, causal analysis, or guaranteed forecast accuracy. See [future work](DEVELOPMENT_ROADMAP.md).
